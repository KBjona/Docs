---
title: Pedro Commands
---
Ivy includes a built-in command for controlling the robot's movement to follow a path using
[Pedro Pathing](https://pedropathing.com). To use it, add the following
static import:

```java
import static com.pedropathing.ivy.pedro.*;
```

All Pedro commands take a `Follower` as their first argument. Usually your Follower
is one created from your [Constants](../pathing/constants) file's `create()` method. 
Pedro commands return regular Ivy `Command`s, so they work just like any other Ivy command.
## Follow

Makes the robot follow any [`Path`](../pathing/reference/api). The command finishes when the follower
is no longer busy (i.e. the robot has reached the end of the path).

```java
Command goToBasket = follow(follower, basketPath);
```

<Callout title="Note on Heading Interpolation" type="info">
    `follow()` executes the path using whichever `interpolation` method was defined for the specific `Path` originally. More info at [interpolation guide](../pathing/reference/interpolation).
</Callout>

## Composing Pedro Commands

Since Pedro commands are regular Ivy commands, you can compose them with
everything else. For example:

```java
Command auto = sequential(
    follow(follower, shootPreloads),
    Shooter.shoot(), // Call the shoot Command.
    instant(() -> claw.open()),
    parallel( // Both start the path and run the intake simultaneously.
        follow(follower, pickupCloseSpikemark),
        instant(() -> intake.activate())
    )
/* ... */
);
```

<Callout title="Note" type="info">
    This page is compatible with Pedro 3, more on that on the [**Pedro Pathing**](/docs/pathing) docs.
</Callout>
