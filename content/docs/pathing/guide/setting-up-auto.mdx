This guide will walk you through making an autonomous mode using PedroPathing, we will break it down into several sections so it is easy for you to understand

Before creating our paths, we first need a `Follower`.

The follower controls the drivetrain, keeps track of the robot's position using the localizer, and runs the path following algorithm configured in your `Constants` file.

If you haven't configured your robot yet, see the [Constants](/docs/pathing/constants) page first.

<Callout title="Tuning" type="warning">
  This guide assumes you have tuned your robot already, if you haven't, please [tune your robot](/docs/pathing/tuning)
</Callout>

### Creating the Follower

First, import the `Follower` and your `Constants` file:

```java
import com.pedropathing.follower.Follower;

import org.firstinspires.ftc.teamcode.pedroPathing.Constants; //Should match your file location
```

Then create a follower variable inside your OpMode:

```java
public class ExampleAuto extends OpMode {

    private Follower follower; //Add this
```

The `create()` method in your `Constants` class creates a follower using the drivetrain, localizer, and algorithm you configured.

Create the follower inside your `init()` method:

```java
@Override
public void init() {
    follower = Constants.create(hardwareMap);
}
```

`init()` runs when the OpMode is initialized, before the Start button is pressed.

<Callout title="Note" type="info">
    Make sure your `Constants` import matches where the file is located in your project. This example uses the location in the quickstart
</Callout>
